# Зміни

## 1.0.0 — 2026-11-08

Перший випуск.

- Прийом підписаних webhook ukrainealarm (RSA + час ±5 хв, захист від повторів, секретний шлях).
- Стан усієї України в пам'яті; рівні загрози `Red` (ракетна небезпека), `Yellow` (загроза БпЛА),
  `Unknown`, переходи в будь-якому порядку.
- Звірка з API в межах ліміту (~1 запит/хв, `POLL_INTERVAL`), узгодження webhook і знімків за
  годинником ukrainealarm, захист від хибного масового відбою.
- SQLite: журнал подій, сесії тривог, окремі сесії загроз, поточний стан; ретенція.
- Локальний API v1: `/state`, `/events` (SSE з відновленням, `hello`, `epoch`, `resync`),
  `/regions`, `/stats`, `/health`.
- Публічні сторінки з непримітним індикатором стану; однакова 404 для всього іншого.
- systemd-ізоляція (`systemd-analyze security` 1.3), `MemoryDenyWriteExecute`.
- `alertd-install.sh` (встановлення з архіву) і `alertd-update` (оновлення з GitHub Releases
  з перевіркою SHA256 і походження).
